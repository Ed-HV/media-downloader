# media-downloader
---
Ejecutar el archivo main.sh desde la terminal

```sh
./main.sh
```
---

En la interfaz seleccionar la opcion que desee

```sh
Opciones:

 1. Descargar Video 
 2. Descargar Audio                        
 3. Configuración                            
 4. Salir  

```
***NOTA: las misma opciones te van ir guiando, despues de pegar la url se demora unos minutos en mostrar un mensaje en la interfaz principal y procedera la descarga***
